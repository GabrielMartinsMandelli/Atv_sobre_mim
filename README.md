# 👤 Atividade: Sobre Mim

Projeto de apresentação pessoal desenvolvido como atividade prática para demonstrar conhecimentos básicos de desenvolvimento web, perfil e interesses.

---

## 🚀 Tecnologias Utilizadas

* **HTML5**: Estruturação de conteúdo semântico.
* **CSS3**: Estilização e formatação visual.
* **JavaScript**: Interatividade da página *(opcional)*.

---

## ✨ Conteúdo da Página

* **Apresentação**: Breve biografia e introdução pessoal.
* **Hobbies e Interesses**: Informações sobre gostos pessoais e atividades no tempo livre.
* **Habilidades**: Principais conhecimentos e ferramentas em aprendizado.
* **Contato**: Links diretos para redes sociais e formas de comunicação.
